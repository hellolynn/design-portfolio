1. **Install dependencies:**
   ```bash

### Adding a new page
To add a new page:
1. Create a new `.md` file in the `/_posts` directory.
2. Follow the YAML front-matter format (Title, Date, Thumbnail).
3. Run `bundle exec jekyll serve` to preview.
