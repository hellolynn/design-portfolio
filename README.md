## ✨ What I used
* **Engine:** [Jekyll 4.4.1](https://jekyllrb.com/)
* **Language:** Ruby 3.2.2
* **Hosting:** GitHub Pages
* **Framework:** Bootstrap 5.3

## 📟 Stuff to remember

### Local development
To run this project locally and preview changes:

1. **Install dependencies:**
   ```bash
   bundle install

### Adding a new page
To add a new page:
1. Create a new `.md` file in the `/_posts` directory.
2. Follow the YAML front-matter format (Title, Date, Thumbnail).
3. Run `bundle exec jekyll serve` to preview.
